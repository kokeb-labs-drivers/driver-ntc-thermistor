Detailed Description

template<typename Derived>
class ntc_thermistor::AdcInterface< Derived >

CRTP base of the platform ADC port.

The base declares no hook itself (a forwarding hook would turn a missing override into infinite recursion); the driver checks your class with the AdcPort concept.
