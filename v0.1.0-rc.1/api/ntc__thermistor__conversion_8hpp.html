Detailed Description

From an ADC code to a temperature: the divider, the curve, the bound, and the helpers around them. Pure functions of a Config and a code; no port, no state.

The pipeline (docs/conversion.md): classify the code (open, short, out of scale), the divider to ohms, the curve to milli-degrees Celsius (a table interpolated in ln R, or the beta equation), the window, the offset, and the uncertainty bound. Only integer arithmetic: no libm, no floating point, no loop without a constant bound.
