constexprnoexcept

The pure conversion: the maths for an ADC code, with no port and no state.

Use it to turn a code the application already has into a temperature, or to test a configuration. A code is the mean code of one reading.

Parameters
configThe configuration; it is validated first.
mean_codeThe ADC code, 0 to 2^adc_bits - 1.
Returns
The reading, or InvalidArgument, CodeOutOfScale, OpenCircuit, ShortCircuit, BelowRange or AboveRange.

◆ SelfHeatingMicrowatts()

constexpr uint32_t ntc_thermistor::SelfHeatingMicrowatts ( const Config &  config,
uint32_t  r_ntc_ohm 
)
constexprnoexcept

The power the divider puts into the thermistor, in microwatts: V^2 * Rn / (Rs + Rn)^2.

Needs divider_supply_mv; a ratiometric configuration does not know the supply and gets 0. Divide by the part's dissipation constant (mW/K in your mounting) for the temperature rise.

Parameters
configThe configuration.
r_ntc_ohmThe thermistor's resistance.
Returns
Microwatts, rounded; 0 when the supply is not declared.
