Detailed Description

NTC thermistor driver: the one header to include.

Copyright
Copyright (c) 2026 The driver-ntc-thermistor authors. SPDX-License-Identifier: MIT

ntc_thermistor::NtcThermistor<Port> reads any NTC thermistor wired in a resistor divider to an ADC channel of your port (see ntc_thermistor_adc_interface.hpp) and returns the temperature in milli-degrees Celsius. The part is data (Config::curve); the driver knows none. No platform code, no heap, no exceptions, no lock, no floating point.
