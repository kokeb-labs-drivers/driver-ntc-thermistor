Detailed Description

template<AdcPort Port>
class ntc_thermistor::NtcThermistor< Port >

Driver for one NTC thermistor in a resistor divider on an ADC port.

Lifecycle: construct with the configuration (no I/O), then EnsureInitialized(), the one way to start; use; replace the configuration with SetConfig(). Every call that touches the port returns Error::NotInitialized until EnsureInitialized() has succeeded; no call starts it as a side effect.

Optional hooks: void DelayUs(uint32_t) (the wait between samples, sample_delay_us, and the settling time, settle_us; a Config that needs a wait the port cannot make is InvalidArgument) and bool SetBias(bool) (powers the divider only while sampling).

◆ EnsureInitialized()

template<AdcPort Port>
Result< void > ntc_thermistor::NtcThermistor< Port >::EnsureInitialized ( )
noexcept

Start the driver, once: the only way to initialise it.

Checks the configuration (and that the port has the hooks it needs), brings the ADC up and, when the port has SetBias(), switches the divider off so that the first reading starts from a known state. After it succeeds, later calls return Ok at once with no I/O. After it fails, the driver stays uninitialised and the next call starts again.

Returns
Ok, InvalidArgument (the configuration fails Validate() or needs a hook the port lacks; no port call) or Bus.
