◆ Error

enum class ntc_thermistor::Error : uint8_t
strong

Why a call failed. Values 0 to 9 are the shared base set; this driver's own values start at 16.

A thermistor read through an ADC has no bus protocol, no identity and no checksum, so Timeout, DeviceIdMismatch, Crc, Busy, DeviceFault and Unsupported are never returned.

Enumerator
Ok 

The call succeeded.

NotInitialized 

EnsureInitialized() has not succeeded yet.

InvalidArgument 

A Config is out of range or inconsistent; nothing was read.

Bus 

A port hook returned false (ADC read or bias switch failed).

Timeout 

Not returned by this driver.

DeviceIdMismatch 

Not returned by this driver.

Crc 

Not returned by this driver.

Busy 

Not returned by this driver.

DeviceFault 

Not returned by this driver.

Unsupported 

Not returned by this driver.

OpenCircuit 

The node is at the open rail: broken thermistor, cut wire, missing part.

ShortCircuit 

The node is at the short rail: shorted part or wire, collapsed supply.

BelowRange 

Colder than the curve or the window, or the resistance is above it.

AboveRange 

Hotter than the curve or the window, or the resistance is below it.

Unstable 

The samples of one reading differ by more than max_spread_codes.

CodeOutOfScale 

A sample is at or above 2^adc_bits: the port and adc_bits disagree.

◆ Validate()

constexpr Error ntc_thermistor::Validate ( const Config &  config)
constexprnoexcept

Check a configuration without touching the hardware.

A curve is exactly one of table mode (2 to 256 rows, resistance strictly falling, temperature strictly rising), Steinhart-Hart mode (bounded coefficients, 1/T rising with ln R, a declared window) or beta mode (r0_ohm, b_kelvin in range, b_t2_mc not the reference, and a window that is declared). An empty curve is refused: no part is ever assumed. A wait is at most kMaxWaitUs.

Parameters
configThe configuration.
Returns
Error::Ok or Error::InvalidArgument.
