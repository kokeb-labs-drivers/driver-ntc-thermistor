Detailed Description

Example curves as data. The driver includes this header nowhere: a preset is a convenience, and a part is added by writing a Curve, never by changing the driver.

presets::kTdkNtcg163jf103ft1s is the worked example of the documentation: a 10 kOhm 0603 chip thermistor with a 39-row table. Its rows are a secondary listing of the vendor's nominal column and are unverified: the datasheet prints no table (docs/presets.md, docs/worked-example.md). presets::kGeneric10kB3950 holds the typical values of the common 10 kOhm / 3950 K class: there is no single datasheet for it, so read yours and override. Neither carries a valid window: a Config still declares min_temperature_mc and max_temperature_mc (beta mode requires them).

Config{.curve = presets::kTdkNtcg163jf103ft1s} is a valid table-mode configuration; Config{.curve = presets::kGeneric10kB3950, .min_temperature_mc = ..., .max_temperature_mc = ...} a valid beta-mode one.
