Detailed Description

What the thermistor is: a table, Steinhart-Hart coefficients, or R at a reference temperature and the beta value.

A non-empty table selects table mode. Otherwise a non-zero sh_b_e15 selects Steinhart-Hart mode (1/T = A + B ln R + C (ln R)^3, R in ohms, T in kelvin) and a zero one selects beta mode, which uses r0_ohm, ref_temperature_mc and b_kelvin. A curve is data: a part is added by writing a Curve, never by changing the driver. tools/ntc_table.py makes a table from any of these descriptions or from a vendor list.
