Detailed Description

Optional ESP-IDF layer: a Config built from the CONFIG_NTC_THERMISTOR_* Kconfig options.

Copyright
Copyright (c) 2026 The driver-ntc-thermistor authors. SPDX-License-Identifier: MIT

Include it only where menuconfig should choose the defaults; without Kconfig KconfigDefaults() equals Config{} (no part: Validate() refuses it). One configuration per program: every translation unit of one program must see the same CONFIG_ values, and no driver header includes this one (handbook KB-CPP20-018).
