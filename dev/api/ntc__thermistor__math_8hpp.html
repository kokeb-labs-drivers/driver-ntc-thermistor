Detailed Description

Integer arithmetic of the NTC thermistor driver: a binary logarithm, rounded division and saturating multiplication, with no libm and no floating point.

Everything is constexpr. No function divides by zero or shifts by a count it has not bounded. SatMul, SatAdd and DivRoundU never overflow; DivRound, AbsDiff and Ln16 have the preconditions stated on each (handbook KB-CPP20-012, -020, -058).
