# NTC_THERMISTOR Driver API reference {#mainpage}

The classes, types and registers of the NTC_THERMISTOR driver, generated from the headers in `inc/`.

Start with ntc_thermistor::NTC_THERMISTOR, the driver, and ntc_thermistor::AdcInterface, the base of the port you write.
Errors are ntc_thermistor::Error inside ntc_thermistor::Result; the configuration is ntc_thermistor::Config.

The guides, with examples that compile, are on the documentation site: <a href="../">NTC_THERMISTOR Driver
documentation</a>.
